농구 실사 두 컷의 **지면 소실선**을 실측해 뒀다 (2026-08-07). 소스는
`C:\Users\user\Desktop\농구 폴더\(푸티지)\PRESS ON _ #3-N.mov` (전부 4096×2160).

```
#3-2  1인칭 발밑   y_h = −1.174 × 프레임높이   (R² 0.996~0.997, 3프레임)
#3-5  3인칭 드리블  y_h =  0.477 × 프레임높이   (R² 0.981~0.986, 4프레임)
```

**재는 법** — 초점거리는 필요 없다. 카메라 정면으로 뻗는 코트 타일 이음매의 화면상
좌우 간격은 `s(y) = k·(y − y_h)` 로 선형이라, 여러 y 밴드에서 열 프로파일의
자기상관 주기를 재고 로버스트 회귀하면 x절편이 소실선이다. 가로줄 주기(∝ (y−y_h)²)로
재는 쪽은 고주파 텍스처에 락돼 실패했다 — 세로줄 간격 쪽이 훨씬 견고하다.

**직관과 반대인 것:** 1인칭이 3인칭보다 **덜** 눕는다. 1인칭은 지면을 거의 수직으로
내려다봐 평면도에 가깝고, 3인칭은 스치는 각도라 강하게 압축된다. 같은 UI 판이라도
좌 화면은 먼 쪽이 ~70% 로만 줄고 우 화면은 ~30% 까지 줄어든다.

**#3-2 는 10초쯤부터 틸트업**한다 (10.0s 에 y_h 가 −0.251 로 올라간다). 고정 코너핀은
앞 구간(0~6초)에서만 맞는다.

적용 스크립트: 바탕화면 `뉴턴_지면기울기_좌_1인칭.jsx` / `뉴턴_지면기울기_우_3인칭.jsx` —
선택 레이어의 위치·크기를 그대로 두고 아래 변만 고정해 위 변을 소실점 쪽으로 당긴다.
배경 클립을 이름(`#3-2`/`#3-5`)으로 자동으로 찾아 `sourcePointToComp` 로 환산하므로
배경이 크롭·확대돼 있어도 맞는다.
