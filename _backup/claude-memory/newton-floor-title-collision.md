1인칭 농구 지면에서 **타이틀 알약과 판정 마크는 제 크기로는 둘 다 못 들어간다.**
배치를 옮겨서 풀 문제가 아니다 — 자리가 물리적으로 모자란다.

실측 (`scripts/audit_fp_bands.mjs` · 눈높이 1.70m · fov 60° · 시선 MAT −52°):

```
화면 하단에 닿는 전방거리   0.77m
빔 원단                    1.90m
→ 1인칭에 보이는 바닥이 1.13m 뿐인데
  코치 판 + 타이틀 알약 + 판정 마크 세 층이 다 들어가야 한다

지면 UI 프레임   NDC −1.389 ~ 0.319
알약 행          NDC  0.102 ~ −0.146   (TOK.headY 340 / 대지 2670 + CAPHEAD_H)
마크 상단        NDC  0.137            ← 알약 행 **안**이다
알약을 마크 위로 올리려면 상단이 0.385 여야 하는데 프레임 far 끝이 0.319 다
```

**Why:** 이걸 모르면 계속 마크를 앞뒤로 밀게 된다. 실제로 그랬다 — 앞으로 밀면
타이틀을 침범하고, 뒤로 밀면 화면 아래로 잘린다. 화면에서 **앞 = 위**라 두 문제가
같은 축에 있다. 자리를 *만드는* 방법은 시선 각도뿐이고(GAZE MAT −52°) 그건 이미 썼다.

**How to apply:** 남은 해법은 **알약이 접히는 것** 하나다. `pillLeads` 에서 스텝백
(`BK_T1`·`BK_B2~4`)을 빼 뒀으므로 `TOK.collapse` 가 살아나 동작명이 빠지고 링만 남는다 —
다만 `TOK.hold`(2.8s) **뒤에야** 접힌다. 겹쳐 보이는 건 그 2.8초 창이다.

미결 선택지 (전체 타이틀·레이아웃 개선 때 결정):
- **A** `TOK.hold` 2.8 → 1.2s. 값 하나. 조각 단계는 0.5배속 2초짜리라 동작명을 오래 띄울 이유가 없다.
- **B** 알약 자체 축소(`TOK.ring`). 러닝·복싱 알약까지 같이 줄어든다.

판정은 감으로 하지 말 것 — `node scripts/audit_fp_bands.mjs <스테이지>` 가 세 층을
**같은 자(화면 NDC y)** 로 재 준다. 층마다 좌표계가 달라서(빔 uv · 대지 px · 미터)
하나를 옮기면 다른 하나를 침범하는 게 이 문제의 구조다.
