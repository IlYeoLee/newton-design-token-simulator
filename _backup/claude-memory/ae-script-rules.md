애프터이펙트용 `.jsx` 를 쓸 때 세 가지를 지킨다. 셋 다 실제로 크게 당한 것이다.

**① `alert()` 를 쓰지 않는다.** AE 알림창이 메인 창 **뒤로 깔려** 클릭이 안 먹는다. 스크립트는
이미 끝났는데 AE 가 통째로 멈춘 것처럼 보이고, 모달이 물고 있어 강제종료도 잘 안 된다.
결과는 파일(예: 바탕화면 `.txt`)로 남기거나, 타임라인에 결과가 보이는 것으로 확인하게 한다.
2026-08-05 에 키프레임 960개 스크립트에서 겪었다 — 창을 `SetForegroundWindow` 로 꺼내
`BM_CLICK` 을 보내서야 풀렸다.

**② 프로퍼티는 `matchName` 으로 잡는다.** 사용자의 AE 는 **한국어판**이라 이름으로 찾으면
전부 실패한다(`midtone blue` 가 아니라 `파랑 균형`). 조용히 건너뛰어 "추가는 됐는데 아무
반응이 없다" 가 된다. 버전마다 ID 가 다를 수 있으니 진단 스크립트로 실제 matchName 을
먼저 뽑아 확인한다.

**③ 마스크 키프레임은 꼭짓점 순서를 고정한다.** AE 는 마스크를 **꼭짓점 번호 순**으로
보간한다. 볼록껍질(convex hull) 같이 시작점이 회전할 수 있는 방법으로 만들면 프레임마다
대응이 바뀌어 마스크가 우글거린다. 실측: 시작점이 tl↔bl 로 5번 뒤집히며 꼭짓점이
1722px 씩 순간이동 → 순서 고정 후 5.1px.

진단이 필요하면 마스크는 이펙트 목록에 **안 들어간다**는 것도 기억할 것 —
`ADBE Mask Parade` 를 따로 읽어야 한다. 트랜스폼도 마찬가지다.
