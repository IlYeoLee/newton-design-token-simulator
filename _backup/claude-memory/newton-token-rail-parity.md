발자국 토큰을 좌/우 교대로 흘릴 때 **개수는 반드시 짝수**, **순환 구간은 간격의 정수배**여야 한다.

좌/우를 인덱스 홀짝(`i % 2`)으로 정하는데, 홀수 개면 한 바퀴 돌아온 토큰(i=N−1 → i=0)이
앞 토큰과 같은 홀짝이 되어 같은 발이 연속된다. 순환 구간이 간격의 배수가 아니면
되돌아온 토큰만 간격까지 어긋난다(2.45m 구간에 0.98m 간격 → 마지막만 0.49m).

**적용된 곳** — `src/session.js` `_paceFeetTick` 의 `N` 을 짝수로 강제(2026-08-06 커밋
7f9d203). 이지런은 `floor(2.45/0.98)=2` 라 원래 안 터졌지만 보폭이 바뀌면 드러난다.

유저가 컨셉영상 레일에서 눈으로 잡아냈다: *"가장 큰 문제가 같은발 발자국이 2번연속되는버그"*.
그때 레일은 `ceil` 을 써서 3개였다.

**이지런 P1 실측값** — 보폭 0.98m · 케이던스 137 SPM · 러너 속도 2.24m/s ·
좌우가 중심에서 ∓0.12m 어긋남 · 토큰 지름 0.619m(대지 901px) · 대지 1600×2670 =
1.098×1.832m(1px = 0.686mm).
