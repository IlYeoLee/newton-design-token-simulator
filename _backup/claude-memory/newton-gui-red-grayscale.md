뉴턴 시뮬레이터의 **GUI 크롬(패널·랩·버튼·뱃지·오버레이)은 레드(#FA3030)+회색조만** 쓴다.
뉴턴 4색 중 코랄·샌드·프리즘은 **투사 빛 언어(지면/벽 토큰)** 전용이다 — GUI에 새면 안 된다.
과한 그림자·글로 금지, 아웃라인(테두리)로 상태·버튼을 표현하는 것도 금지 — 채움(면)과
스케일 프레스, 밝기 변화로만 말한다(토스 문법). 2026-08-12 유저 확정, 커밋 f3093ef·1f8c782.

**Why:** GUI에 유채색이 여러 개 돌면 위계가 무너지고 "AI가 만든 티"가 난다. 색은 투사
콘텐츠(빛 언어)의 정보 채널이라 GUI가 그 색을 쓰면 의미가 오염된다.

**How to apply:** 뉴턴 계열 UI(시뮬레이터·랩·UX북 이식물·aura 앱 GUI)를 만들거나 고칠 때
액센트는 레드 하나, 나머지는 흰~회색 단계만. 선택 상태 = 레드 필, 보조 = 회색 필.
