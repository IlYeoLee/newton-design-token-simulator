00. 핵심 개념 — Step-type vs Prediction-type
================================================================================

같은 종목 안에서도 단계에 따라 UI 문법이 달라져야 한다.
그냥 "러닝은 발자국, 복싱은 타겟, 농구는 화살표"로 끝내면 안 된다.

■ 핵심 구분

스트레칭 / 사전 익히기 = Step-type 티칭 UI
  사용자가 직접 밟고, 맞추고, 천천히 따라 하게 하는 단계.
  "여기를 밟아", "이 순서로 움직여", "지금은 1단계야"처럼
  명시적이고 친절한 UI가 필요하다.

실전 운동 = Prediction-type 수행 UI
  사용자가 이미 기본 흐름을 익힌 뒤, 방해 없이 앞으로 나올 위치와
  리듬을 예측하게 하는 단계.
  "다음 발이 어디로 이어질지", "곧 방향 전환이 온다" 정도만 보여주는
  가볍고 예측적인 UI가 맞다.

■ 근거 (보행 프로젝션 논문)
  A Wearable Projector-based Gait Assistance System and its Application
  for Elderly People (ResearchGate)
  - 보행 중 바닥에 보폭 정보를 투사하는 웨어러블 프로젝터 시스템 제안
  - 76–91세 건강한 고령자 10명 대상, 바닥 시각 단서가 보폭 조절에 효과 있고
    장치 수용성도 확인
  - "바닥에 투사된 단서를 밟아가며 움직이는 방식"은 NEWTON의
    스트레칭/사전익히기 단계 근거로 사용 가능

■ NEWTON 세션 UI 3단계 구조

  단계          목적                  UI 성격                       사용자 느낌
  ─────────────────────────────────────────────────────────────────────────
  스트레칭      몸 열기, 관절 범위 확인   느린 Step-type, 큰 토큰, 텍스트  "천천히 따라 하면 된다"
  사전 익히기   Pack 순서·리듬·타이밍     Step-type 중심, 숫자·단계·반복  "움직임을 배운다"
  실전 운동     원본 Pack 흐름에 근접     Prediction-type, 선행 단서 최소  "방해 없이 플레이한다"

토큰 문법: 바닥 종목 = "위치·타이밍 가이드", 벽면 종목 = "폼·타이밍 가이드"
이 3단계 구조와 정확히 붙여야 한다.

■ 한 문장 정리
  NEWTON의 프로젝션 UI는 처음부터 실전처럼 보여주는 게 아니라,
  처음에는 밟게 하고, 중간에는 이해시키고, 실전에서는 예측하게 만들어야 한다.

01. 공통 세션 플로우 보드
================================================================================

보드 목적:
  Pack을 고른 뒤, 사용자가 실제 운동으로 들어가고 단계가 넘어가는 방식을 정의.
  앱은 운동 전 세팅까지만 맡고, 운동 중에는 지면/벽면 UI, 음성, 웨어러블,
  발 제스처가 흐름을 이끈다.

■ 전체 흐름

  Pack 진입
  ↓
  Pack 상세 확인
  ↓
  오늘 세션 설정 (장소 / 난이도 / 모드 / 컨디션 / 부상 체크)
  ↓
  기기·투사면 준비 (웨어러블 / 스테이션 / 이어폰 / 지면·벽면)
  ↓
  준비 완료 — 발 두 번 탭 → 시작
  ↓
  1. 스트레칭 (Slow Step-type)
  ↓ 단계 완료 — 발 두 번 탭 → 사전 익히기
  2. 사전 익히기 (Step-type + Guide)
  ↓ 단계 완료 — 발 두 번 탭 → 실전 운동
  3. 실전 운동 (Prediction-type)
  ↓
  세션 종료
  ↓
  리포트

■ 화면 상태 구분

  상태            화면/투사면       사용자가 하는 일           시스템이 하는 일
  ────────────────────────────────────────────────────────────────────────────
  Pack 상세       App              Pack을 고른다              Pack 유형·출처·추천 모드 표시
  오늘 세션 설정   App/Station      장소·난이도·모드·컨디션 선택   오늘 실행 기준 생성
  기기 준비       App/지면/벽면     착용 상태 확인             웨어러블·스테이션·이어폰 연결 확인
  Ready          지면/벽면         발 두 번 탭으로 시작        시작 UI 투사
  Stretching     지면/벽면         천천히 따라 한다           큰 토큰·텍스트·느린 큐 출력
  Learn          지면/벽면         순서와 리듬을 익힌다        숫자·링·고스트·반복 피드백 출력
  Real Play      지면/벽면         실전처럼 움직인다          예측 단서만 최소로 출력
  Report         App              결과를 확인한다            일치도·근접도·안전 기록 정리

■ 단계별 UI 문법
  처음에는 밟게 하고, 중간에는 배우게 하고, 실전에서는 예측하게 한다.

  단계          UI 방식             성격                     토큰 밀도
  ──────────────────────────────────────────────────────────────
  스트레칭      Slow Step-type      몸 열고 안전 기준 확인      높음
  사전 익히기   Step-type + Guide   순서·리듬·타이밍 학습        가장 높음
  실전 운동     Prediction-type     방해 없이 흐름 수행         낮음

■ 핵심 카피
  세션은 앱에서 시작되지만, 운동 중 흐름은 몸으로 넘긴다.
  사용자는 Pack을 고르고 오늘의 기준을 정한 뒤, 발 두 번 탭으로 운동을 시작한다.
  스트레칭과 사전 익히기에서는 크게 보여주고 천천히 따라 하게 하며,
  실전에서는 방해를 줄이고 다음 움직임을 예측하게 한다.

02. 러닝 세션 와이어프레임
================================================================================

보드 제목: 러닝 Pack이 실제 지면 가이드로 펼쳐지는 과정
보드 목적: 스트레칭 → 사전 익히기 → 실전 러닝으로 넘어가며 바닥 UI가
           "밟는 가이드"에서 "예측하는 리듬"으로 바뀌는 과정을 보여준다.

■ Pack 진입 정보
  Pack     : 션의 마지막 1km 페이스 Pack
  유형     : Creator Pack / 루틴형
  장소     : 집밖 / 야외 지면
  난이도   : 기본
  모드     : SAFE + BOOST
  핵심 경험: 후반에 무너지는 페이스를 다시 붙잡는 러닝 리듬

■ 0. Ready
  목적: 시작 전, 착용과 지면 상태 확인
  지면 UI:
    [중앙 시작 원] READY
    상태: 웨어러블 착용 완료 / 이어폰 연결 완료 / 지면 투사 준비 완료
    조작: 발 두 번 탭 → 시작
  ※ 발자국은 아직 나오면 안 됨. 시작 원 하나가 더 명확.

■ 1. Stretching  (Slow Step-type)
  목적: 발목·종아리·보폭을 천천히 준비
  지면 UI:
    STRETCH 1/3
    "왼발을 앞 원 위에 올려주세요 / 10초 유지"
    [큰 왼발 원] [작은 중심 기준선]
  토큰: 큰 stepMark / 유지 시간 링 / 짧은 텍스트 / 느린 음성 큐
  발 조작: 동작 완료 후 발 두 번 탭 → 다음 스트레칭

■ 2. Learn / 사전 익히기  (Step-type + Guide)
  목적: Pack의 페이스·보폭·리듬을 먼저 익힘
  지면 UI:
    LEARN 2/4 — 션의 마지막 1km 리듬
    1 왼발  2 오른발  3 왼발 / "링이 사라질 때 밟기"
    ① 왼발 원   ② 오른발 원   ③ 왼발 원
       timing ring  timing ring   timing ring
       중앙 진행 대시
  토큰: stepMark / orderPulse / timingRing / pathLane / 성공 리플
  피드백: 좋아요 / 조금 빨라요 / 보폭을 조금 줄여요
  발 조작: 반복 완료 후 발 두 번 탭 → 실전 러닝

■ 3. Real Run / 실전 러닝  (Prediction-type)
  목적: 배운 리듬을 실제 러닝 흐름에서 유지
  지면 UI:
    RUN 03:20
    현재 발밑에는 없음
    전방 1.4m 이후부터 — 다음 발자국 100% / 그 다음 60% / 그 다음 35%
    중앙 진행 대시가 앞으로 흐름
  토큰: 선행 stepMark / pathLane / 리듬 펄스 / 위험 시 짧은 경고
  웨어러블: 초반 SAFE / 후반 리듬 저하 감지 시 BOOST
  ※ 중요: "여기 밟아!"가 아니라 앞사람의 발자국을 따라가는 느낌.
     발자국은 발밑에 뜨면 안 되고 전방에서 먼저 나타나야 한다.
     "발밑 0~1.4m는 출현 용도로 무효" 기준 적용.

■ 4. Finish / 리포트 연결
  App Report: 페이스 유지 / 후반 리듬 / 보폭 안정성 / BOOST 개입 구간 / 다음 추천
  다음 세션 제안:
    "후반 리듬이 800m 이후 무너졌어요.
     다음 세션은 사전 익히기 시간을 조금 늘릴게요."

■ 핵심 문장
  러닝 UI는 처음에는 발밑을 밟게 하고, 실전에서는 앞쪽 리듬을 예측하게 한다.
  (밟는 리듬 → 예측하는 페이스)

03. 복싱 세션 와이어프레임
================================================================================

보드 제목: 복싱 Pack이 벽면 가이드로 펼쳐지는 과정
보드 목적: 스트레칭 → 사전 익히기 → 실전 대련으로 넘어가며 벽면 UI가
           "자세를 보여주는 화면"에서 "반응하게 만드는 상대"로 바뀌는 과정.
※ 복싱은 벽면이 메인 화면. TV처럼 텍스트·고스트·타겟·점수·콤보를 더 얹어도 자연스럽다.

■ Pack 진입 정보
  Pack     : 복싱 고수의 입문 회피 스텝 Pack
  유형     : Skilled User Pack / 기초+루틴형
  장소     : 집 안 / 벽면 투사
  난이도   : 입문
  모드     : QUIET + SAFE
  핵심 경험: 집 안에서도 발소리 부담 없이, 회피와 잽의 리듬을 짧게 익히는 첫 스파링

■ 0. Ready
  벽면 UI:
    READY — "가드 위치를 맞춰주세요"
    [반투명 기본 가드 실루엣] [사용자 위치 기준선]
    [하체 웨어러블 착용 완료] [스테이션 연결 완료]
    발 두 번 탭 → 시작
  ※ 시작 전부터 고스트 실루엣을 보여줘도 됨.

■ 1. Stretching  (Ghost + Text Guide)
  목적: 가드 자세·어깨·고관절·발목을 천천히 연다
  벽면 UI:
    STRETCH 1/4 — "가드를 올리고 중심을 낮춰주세요 / 10초 유지"
    [전문가 고스트: 기본 가드 자세] [어깨 회전 방향 표시] [하체 스탠스 기준선]
  토큰: ghost / 짧은 텍스트 / 자세 기준선 / 유지 시간 링 / 느린 음성 큐
  발 조작: 완료 후 발 두 번 탭 → 다음 스트레칭
  ※ 여기서 타겟을 치게 하면 안 됨. 가드·중심·스탠스를 먼저 맞추는 화면.

■ 2. Learn / 사전 익히기  (Ghost + Target + Order Guide)
  목적: 회피 → 복귀 → 잽 순서를 천천히 익힘
  벽면 UI:
    LEARN 2/5
    1 왼쪽으로 피하기  2 중심으로 복귀  3 잽 / "타겟 링이 작아지는 순간 치기"
    [왼쪽 회피 영역] [중앙 가드 고스트] [오른쪽 타겟 원]
    ① 회피  ② 복귀  ③ 잽 targetMark
  토큰: ghost / targetMark / orderPulse / 타겟 수축 링 / 성공 히트 이펙트
  피드백: 좋아요 / 조금 빨라요 / 가드가 내려갔어요 / 중심을 더 낮춰요
  ※ 거의 리듬게임 튜토리얼처럼 가도 됨.

■ 3. Real Sparring / 실전 대련  (Reaction-type)
  목적: 배운 회피와 잽을 짧은 가상 대련으로 수행
  벽면 UI:
    SPARRING 01:20
    [가상 상대 실루엣] [상대 공격 범위] [회피 방향 짧은 표시] [수축 타겟]
    흐름: 상대 공격 범위 등장 → 회피 → 빈 타이밍에 타겟 수축 → 잽 히트 → 짧은 콤보 피드백
  토큰: ghost/가상 상대 / targetMark / 공격 범위 / 짧은 orderPulse / 히트 이펙트
  웨어러블: QUIET(착지 소음·충격 완화) / SAFE(균형 붕괴·과회전 시 개입)
  ※ 실전에서는 텍스트를 줄이고 공격 범위·타겟 수축·짧은 성공 피드백만 남긴다.

■ 4. Pause / 단계 전환
  콤보 세트 완료 → 벽면 완료 UI 표시 → "한 번 더 / 다음 단계" → 발 두 번 탭 → 다음 단계
  ※ 운동 수행 중에는 발 제스처 잠금. 완료 화면에서만 활성화.

■ 5. Finish / 리포트 연결
  App Report: 회피 타이밍 / 잽 타겟 성공률 / 가드 유지 / 중심 흔들림 / QUIET·SAFE 개입 구간
  다음 세션 제안:
    "회피 후 복귀가 조금 늦었어요.
     다음 세션은 사전 익히기에서 복귀 스텝을 한 번 더 연습할게요."

■ 핵심 문장
  복싱 UI는 처음에는 자세를 보여주고, 중간에는 콤보를 가르치고,
  실전에서는 상대에게 반응하게 만든다. (보는 자세 → 익히는 콤보 → 반응하는 대련)


================================================================================
04. 농구 세션 와이어프레임
================================================================================

보드 제목: 농구 Pack이 지면 가이드로 펼쳐지는 과정
보드 목적: 스트레칭 → 스텝 분해 → 실전 스텝백으로 넘어가며 바닥 UI가
           "쪼개서 익히는 스텝"에서 "전환 순간만 남기는 단서"로 바뀌는 과정.
※ 농구는 러닝처럼 바닥 UI지만, 핵심이 보폭이 아니라
   플랜트 풋·방향 전환·스텝백 타이밍이라 가장 섬세하게 쪼개야 한다.
   그냥 경로를 보여주면 "따라 걷는" 느낌이 나고 프로 스텝백 감각이 죽는다.

■ Pack 진입 정보
  Pack     : 커리의 수비 거리 삭제 스텝 Pack
  유형     : Pro Pack / 하이라이트형
  장소     : 실내 코트 / 지면 투사
  난이도   : 원본 근접
  모드     : SAFE + LOAD
  핵심 경험: 수비수와의 거리를 한순간에 벌리는 스텝백의 방향 전환 타이밍

■ 0. Ready
  목적: 시작 전, 착용과 지면 상태·스탠스 기준 확인
  지면 UI:
    [중앙 시작 원] READY
    상태: 무릎 모듈 착용 완료 / 스테이션 연결 완료 / 지면 투사 준비 완료
    [좌우 스탠스 기준선]
    조작: 발 두 번 탭 → 시작
  ※ 방향 전환 종목이라 시작 전부터 좌우 스탠스 기준선을 보여줘도 됨.

■ 1. Stretching  (Slow Step-type)
  목적: 무릎·발목·고관절 방향 전환 준비
  지면 UI:
    STRETCH 1/4 — "중심을 낮추고 좌우로 무게를 옮겨주세요 / 각 10초"
    [좌우 스탠스 원] [중심 이동선]
  토큰: 큰 stepMark(좌우) / 중심 이동선 / 짧은 텍스트 / 유지 시간 링
  텍스트 예: "무릎 잠그지 않기", "오른발로 버티기", "중심 낮추기"
  발 조작: 완료 후 발 두 번 탭 → 다음 스트레칭
  ※ 방향 전환은 무릎·발목 부하가 크므로 준비 단계에서 안정성을 먼저 확보.

■ 2. Learn / 사전 익히기  (완전 Step-type + Order Guide)
  목적: 첫 발 → 백스텝 → 플랜트 풋 → 복귀를 천천히 분해해 익힘
  지면 UI:
    LEARN 2/6 — 커리 스텝백 분해
    1 첫 발  2 백스텝  3 플랜트  4 복귀 / "번호 순서대로 밟기"
    ① 첫 발 원   ② 백스텝 원   ③ 플랜트 풋 링(강조)   ④ 복귀 위치 원
       각 stepMark에 orderPulse 숫자
  토큰: stepMark / orderPulse / 플랜트 풋 링 / pathLane(경로 점선) / 복귀 잔상
  피드백: 좋아요 / 첫 발이 늦어요 / 플랜트 발을 더 단단히 / 중심이 떴어요
  발 조작: 반복 완료 후 발 두 번 탭 → 실전 스텝백
  ※ "커리 스텝백"을 바로 하는 게 아니라 움직임의 조각을 익히는 상태.
     숫자 orderPulse가 가장 중요한 구간.

■ 3. Real Stepback / 실전 스텝백  (Prediction-type)
  목적: 배운 스텝을 실제 컷인·전환 흐름에서 수행
  지면 UI:
    STEPBACK 02:40
    컷인 pathLane이 먼저 흐름
    플랜트 풋 링은 방향 전환 직전에만 등장
    전환 화살표는 전환 이벤트 ±윈도우에서만 짧게
  토큰: 컷인 pathLane / 플랜트 풋 링(순간) / directionGuide 화살표(순간) / 위험 시 경고
  웨어러블: SAFE(착지·균형 붕괴 개입) / LOAD(반복 전환 구간 저항 부하)
  ※ 화살표가 계속 떠 있으면 설명처럼 보인다. 전환 직전 짧게만 떠야
     진짜 플레이처럼 보인다.

■ 4. Finish / 리포트 연결
  App Report: 첫 발 타이밍 / 플랜트 풋 안정성 / 백스텝 거리·각도 / 착지 안정성 / SAFE·LOAD 개입 구간
  다음 세션 제안:
    "플랜트 발 착지가 흔들렸어요.
     다음 세션은 사전 익히기에서 플랜트 타이밍을 한 번 더 분해할게요."

■ 핵심 문장
  농구 UI는 스텝을 쪼개 익히게 하고, 실전에서는 전환 순간만 읽게 한다.
  (잡는 중심 → 터지는 전환)
  스트레칭 = 스탠스 원 + 무게 이동
  사전 익히기 = 1·2·3·4 스텝 분해
  실전 = 컷인 경로 + 플랜트 풋 + 순간 화살표

05. 대표 3종목 세션 와이어프레임 비교 보드
================================================================================

보드 제목: 운동마다 다른 방식으로, 같은 Pack 경험을 따라가게 한다

핵심 문장:
  NEWTON의 세션은 모두 스트레칭 → 사전 익히기 → 실전 운동으로 흐르지만,
  종목에 따라 따라 하게 만드는 방식은 다르다.
  러닝은 발밑 리듬을 따라가고, 복싱은 벽면의 폼과 타이밍에 반응하며,
  농구는 방향 전환의 순간을 예측한다.

  구분        러닝                            복싱                        농구
  ─────────────────────────────────────────────────────────────────────────────────────
  대표 Pack   션의 마지막 1km 페이스 Pack       복싱 고수의 입문 회피 스텝     커리의 수비 거리 삭제 스텝
  Pack 유형   Creator / 루틴형                 Skilled User / 기초+루틴형    Pro / 하이라이트형
  투사면      지면                            벽면                        지면
  핵심 학습   페이스·보폭·리듬                  가드·회피·잽 타이밍            첫 발·백스텝·플랜트 풋
  스트레칭    큰 발 위치 원 + 유지 시간          고스트 자세 + 텍스트 가이드     스탠스 원 + 중심 이동선
  사전 익히기 stepMark 밟으며 리듬 학습          고스트+타겟+콤보 순서          1·2·3·4 스텝 분해
  실전 운동   전방 prediction footprint+pathLane 가상 상대 + 수축 타겟          컷인 pathLane + 전환 화살표
  주요 토큰   stepMark/timingRing/pathLane     ghost/targetMark/orderPulse   stepMark/pathLane/directionGuide
  대표 모드   SAFE + BOOST                    QUIET + SAFE                 SAFE + LOAD
  리포트 기준 페이스 유지·후반 리듬              회피 타이밍·가드 유지          플랜트 풋·착지 안정성

■ 핵심 비교 문장
  러닝  — 밟는 리듬에서, 예측하는 페이스로
  복싱  — 보는 자세에서, 반응하는 대련으로
  농구  — 잡는 중심에서, 터지는 전환으로

■ 결론 카피
  처음에는 크게 보여주고, 중간에는 순서를 가르치고, 실전에서는 단서를 줄인다.
  NEWTON의 프로젝션 UI는 운동을 설명하는 화면이 아니라,
  사용자가 실제로 움직이게 만드는 단계별 가이드다.

06. 단계별 UI 밀도 조절 보드
================================================================================

보드 제목: 처음엔 크게 가르치고, 실전에서는 흐름만 남긴다

■ 단계별 정보 밀도
  단계          UI 밀도    목적                     화면 성격
  ──────────────────────────────────────────────────────────
  스트레칭      높음       몸 열기·자세 준비·안전 확인   튜토리얼
  사전 익히기   가장 높음   순서·타이밍·리듬 학습        티칭 가이드
  실전 운동     낮음       실제 흐름 수행             예측 단서

■ UI 요소별 증감 규칙
  UI 요소        스트레칭    사전 익히기    실전 운동
  ────────────────────────────────────────────────────
  텍스트 가이드   많음        중간          거의 없음
  숫자/순서       적음        많음          거의 없음
  발자국/타겟     큼          중간~큼        작고 선행 표시
  타이밍 링       느림        명확함         짧게
  고스트          자세 고정    동작 시연      최소 또는 제거
  피드백          안전 중심    학습 중심      순간 반응 중심
  웨어러블 개입   약하게       보조 중심      모드 목적에 맞게

■ 종목별 UI 밀도 변화
  러닝: 큰 발 원 → 숫자 발자국 → 전방 리듬  (밟는 가이드 → 앞서가는 리듬)
  복싱: 고스트 자세 → 콤보 타겟 → 가상 상대  (설명하는 벽면 → 반응하는 상대)
  농구: 스탠스 원 → 스텝 분해 → 전환 단서    (쪼개서 배우는 스텝 → 전환 순간만)

■ 시각 구조 (가로 타임라인)
  스트레칭          →   사전 익히기         →   실전 운동
  크게 보여줌            순서를 가르침           단서만 남김
  텍스트 많음            숫자/링 많음            텍스트 거의 없음
  느린 속도              반복 학습               실전 리듬

■ 결론 카피
  NEWTON은 처음부터 실전처럼 보여주지 않는다.
  처음에는 밟고 이해할 수 있게 충분히 보여주고,
  익숙해질수록 단서를 줄여 실제 움직임의 리듬을 방해하지 않는다.

07. 난이도별 세션 지원 분기 보드
================================================================================

보드 제목: 같은 Pack도, 난이도에 따라 다르게 가르친다

핵심 문장:
  NEWTON은 Pack의 원본 감각을 바꾸지 않는다.
  대신 선택한 난이도에 따라 단서의 양, 미리보기, 큐 빈도, 판정 허용 범위,
  사전 익히기 밀도를 조절한다.

■ 세 축 구분 (섞으면 안 됨)
  Pack 유형 : 운동 방법론      (기초 / 루틴 / 하이라이트)
  난이도    : 가이드 친절도     (입문 / 기본 / 원본 근접)
  개입 모드 : 몸에 작동하는 물리 개입 (QUIET / SAFE / LOAD / BOOST)

■ 난이도별 UI 차이
  난이도       스트레칭                 사전 익히기              실전 운동
  ─────────────────────────────────────────────────────────────────────────
  입문         큰 토큰·텍스트 많음·느림   단계 분해 많음·숫자·링·반복  실전에서도 일부 가이드 유지
  기본         핵심 준비 동작 중심        주요 순서·리듬만 학습        예측 단서 중심
  원본 근접    짧게 준비                 핵심 전환 구간만 확인        원본 리듬에 가깝게·단서 최소

■ 난이도가 실제로 바꾸는 값
  조절 항목        입문       기본          원본 근접
  ──────────────────────────────────────────────────
  텍스트 설명       많음       짧음          거의 없음
  토큰 크기         큼         기본          작거나 최소
  선행 표시 시간     길게       중간          짧게
  동시 표시 개수     많음       적당히         최소
  숫자/순서 표시     계속 표시   사전익히기 중심  거의 없음
  타이밍 링 속도     느림       기본          원본 리듬 근접
  판정 허용창       넓음       보통          좁음
  반복 횟수         많음       기본          적음
  음성 큐          자세히      핵심만         짧게
  실전 UI 밀도      중간       낮음          매우 낮음

■ 시각 축 (가로 = 난이도)
  입문 ─────────── 기본 ─────────── 원본 근접
  크게 보여줌        핵심만 안내        거의 원본 리듬
  천천히 티칭        예측 단서 중심      단서 최소화
  판정 넓음          판정 보통          판정 엄격

■ 결론 카피
  NEWTON의 난이도는 움직임을 쉽게 바꾸는 기능이 아니라,
  원본 움직임에 다가가는 거리 조절이다.

08. Pack 유형별 운동 방법론 보드
================================================================================

보드 제목: Pack 유형은 난이도가 아니라, 움직임을 익히는 방식이다

핵심 문장:
  기초 Pack은 움직임의 기본 구조를 잡고,
  루틴 Pack은 흐름과 반복을 만들며,
  하이라이트 Pack은 특정 순간의 시그니처를 도전하게 한다.
  얼마나 친절하게 보여줄지는 이후 입문/기본/원본 근접 난이도가 조절한다.

■ Pack 유형 3가지
  Pack 유형        운동 방법론              사용자가 배우는 것          대표 느낌
  ────────────────────────────────────────────────────────────────────────────
  기초 Pack       기본 자세·안정성 익힘       자세·착지·균형·기본 리듬      "일단 몸에 기준을 만든다"
  루틴 Pack       동작 연결·반복 흐름         리듬·지속·전환·반복 수행       "흐름을 타며 몸에 넣는다"
  하이라이트 Pack  숙련자 시그니처 순간 도전     첫 발·전환·타이밍·결정 장면    "보고 저장한 그 장면을 해본다"

  정리: 기초 = 기준 만들기 / 루틴 = 흐름 익히기 / 하이라이트 = 순간 도전하기

■ 세 값이 각각 바꾸는 것
  기초/루틴/하이라이트         → 어떤 움직임을 중심으로 훈련하는가
  입문/기본/원본 근접          → 얼마나 크게·천천히·친절하게 보여주는가
  QUIET/SAFE/LOAD/BOOST      → 몸에 어떤 물리 개입이 들어가는가

■ 종목별 Pack 유형 예시
  러닝:  기초=기본 보폭 안정 / 루틴=마지막 1km 페이스 / 하이라이트=마지막 200m 스퍼트
  복싱:  기초=기본 가드와 잽 / 루틴=회피→복귀→잽 콤보 / 하이라이트=카운터 한 방
  농구:  기초=스탠스와 방향 전환 / 루틴=드리블 컷인 반복 / 하이라이트=커리 스텝백

■ 같은 하이라이트 Pack도 난이도에 따라 다르게 보인다 (커리 스텝백 예)
  입문      : 1 첫 발 → 2 백스텝 → 3 플랜트 → 4 복귀를 크게 분해
  기본      : 주요 스텝 순서와 플랜트 풋 중심
  원본 근접 : 전환 직전 단서만 보여주고 원본 리듬에 가깝게 수행

  → 하이라이트라서 어려운 게 아니라,
    하이라이트라는 움직임을 입문 난이도로도 배울 수 있다.

■ 결론 카피
  Pack 유형은 무엇을 배울지 정하고, 난이도는 어떻게 보여줄지 정한다.


================================================================================
09. 종목 × Pack 유형 × 난이도 매트릭스 보드
================================================================================

보드 제목: 같은 운동도, Pack 유형과 난이도에 따라 다르게 펼쳐진다

■ 큰 구조
  운동 종목 (러닝/복싱/농구)
  ↓
  Pack 유형 (기초/루틴/하이라이트)
  ↓
  난이도 (입문/기본/원본 근접)
  ↓
  세션 단계 (스트레칭 → 사전 익히기 → 실전 운동)

■ 매트릭스 기본형 (무엇을 배울지)
  운동     기초 Pack           루틴 Pack               하이라이트 Pack
  ──────────────────────────────────────────────────────────────────────
  러닝     기본 보폭 안정        마지막 1km 페이스          마지막 200m 스퍼트
  복싱     기본 가드와 잽        회피→복귀→잽 콤보           카운터 한 방
  농구     스탠스와 방향 전환     드리블 컷인 반복            커리 스텝백

■ 러닝 난이도 적용
  Pack             입문                 기본              원본 근접
  ─────────────────────────────────────────────────────────────────────
  기초 보폭 안정     큰 발자국·보폭 텍스트   발자국+링 중심      pathLane 중심
  페이스 루틴        1·2·3 숫자로 박자 학습  전방 발자국 2~3개    리듬 펄스 중심
  스퍼트 하이라이트   짧은 구간 느리게 분해   스퍼트 진입 타이밍    원본 페이스 전환에 가깝게

■ 복싱 난이도 적용
  Pack             입문                 기본            원본 근접
  ─────────────────────────────────────────────────────────────────
  기본 가드/잽       고스트 자세+텍스트      고스트+타겟       타겟 타이밍 중심
  회피 콤보 루틴      1 회피→2 복귀→3 잽     콤보 순서+수축 링   상대 반응 중심
  카운터 하이라이트   공격 범위·회피 방향 표시  공격 범위+타겟     거의 즉시 반응

■ 농구 난이도 적용
  Pack             입문             기본                원본 근접
  ─────────────────────────────────────────────────────────────────
  스탠스 기초        좌우 스탠스 원+텍스트  중심 이동선          균형 피드백 중심
  컷인 루틴          경로를 크게 분해     pathLane+플랜트 링    경로 최소화
  커리 스텝백        1·2·3·4 스텝 분해   플랜트 풋+순간 화살표   전환 직전 단서만

■ 결론 카피
  Pack 유형은 무엇을 익힐지 정하고, 난이도는 어떻게 따라가게 할지 정한다.

10. 운동 중 판정 & 피드백 로직 보드
================================================================================

보드 제목: 잘 따라가고 있는지, 위험하진 않은지, 운동 중 바로 판단한다

핵심 문장:
  NEWTON은 운동 중 발 위치·타이밍·리듬·착지·균형을 읽고 Pack 기준과 비교한다.
  판정은 안전 위험도 / Pack 일치도 / 숙련 근접도로 나뉘며,
  위험한 순간에는 학습 피드백보다 안전 개입이 먼저 작동한다.

■ 판정 우선순위
  실제 수행 센싱
  ↓
  1. 안전 위험도 판정 (위험 착지 / 균형 붕괴 / 과동작 / 충돌 위험)
  ↓
  2. Pack 일치도 판정 (순서 / 방향 / 경로 / 리듬 / 시그니처 구간 유지)
  ↓
  3. 숙련 근접도 판정 (타이밍 정확도 / 리듬 안정성 / 착지 안정성 / 반응 품질)
  ↓
  운동 중 피드백 (지면·벽면 UI / 음성 / 진동 / 웨어러블 개입)

  ※ 안전이 1순위. Pack을 잘 따라 하는 것보다 무릎·발목·균형 붕괴를 먼저 잡는다.

■ 판정 종류
  판정           보는 것                          의미
  ──────────────────────────────────────────────────────────────
  안전 위험도     착지·균형·과동작·충돌 위험          지금 멈추거나 줄여야 하는가
  Pack 일치도    순서·방향·경로·핵심 리듬·시그니처     Pack답게 유지되는가
  숙련 근접도     타이밍·리듬 안정성·착지·반응성       얼마나 능숙하게 수행했는가
  피로 후 유지력  후반 리듬·보폭·반응 저하            지친 뒤에도 유지되는가

■ 피드백 강도 단계
  위험도    시스템 판단      피드백 방식
  ──────────────────────────────────────────────────────────────
  Low       흐름 유지 가능    짧은 힌트·작은 리플·음성 한마디
  Medium    보정 필요        시각 경고·타이밍 교정·웨어러블 미세 조정
  High      즉시 안전 우선    UI 축소·강한 경고·SAFE 전환·세션 일시 중단

  핵심: 잘못할 때마다 점수를 깎는 게 아니라,
        흐름을 유지할 수 있으면 작게 알려주고, 위험하면 바로 개입한다.

■ 종목별 판정 로직
  러닝:  페이스 유지(리듬 펄스 조정) / 보폭 안정(발자국 간격) /
         후반 무너짐(BOOST) / 착지 위험(SAFE·착지 경고)
  복싱:  회피 타이밍("조금 늦어요") / 잽 타이밍(히트 이펙트) /
         가드 유지("가드 내려갔어요") / 중심 흔들림(SAFE) / 소음·충격(QUIET)
  농구:  첫 발 타이밍("첫 발이 늦어요") / 플랜트 풋(플랜트 링 강조) /
         백스텝 거리(복귀 위치 잔상) / 착지 안정성(SAFE) / 반복 부하(LOAD)

■ 결론 카피
  NEWTON의 판정은 사용자를 평가하기 위한 점수가 아니라,
  다음 움직임을 안전하게 이어가기 위한 실시간 판단이다.
  위험한 순간에는 먼저 멈추고, 흐름이 유지될 때는 최소 단서로 리듬만 바로잡는다.

11. Situation Cue 보상 시스템 보드
================================================================================

보드 제목: 성공한 순간에만, 짧게 보상한다

핵심 문장:
  NEWTON의 보상은 점수판이 아니다.
  움직임이 성공한 순간에만 짧은 시각·청각 피드백을 주어 리듬을 끊지 않는다.
  보상은 프로젝션 UI의 일부이며, 실전 흐름을 방해하지 않는 선에서만 등장한다.

■ Situation Cue 6종
  큐              발생 시점                     표현                       지속
  ────────────────────────────────────────────────────────────────────────────
  Hit Glow        타겟·스텝을 정확히 맞춘 순간     토큰 주변 짧은 발광        ~200ms
  Timing Pulse    타이밍 링과 동작이 일치한 순간    링이 리듬으로 한 번 맥동    1박
  Step Combo      연속 성공이 이어질 때           작은 콤보 카운트(2·3·4…)    누적 표시
  Match Rate      구간 종료 시 Pack 일치도        퍼센트 요약(구간 단위)      구간 전환 시
  Ghost Review    사전 익히기·복기 시            전문가 고스트와 내 궤적 겹침  복기 화면
  Clear Reward    세션/세트 클리어 순간          짧은 클리어 연출 + 정리 카피  종료 화면

■ 단계별 보상 밀도 (실전일수록 절제)
  단계          보상 방식
  ──────────────────────────────────────────────
  스트레칭      거의 없음 (안전·자세 확인이 우선)
  사전 익히기   Hit Glow / Timing Pulse / Step Combo — 학습 동기 부여
  실전 운동     Hit Glow·짧은 Timing Pulse만 — 리듬 유지, 숫자·콤보는 절제
  종료          Match Rate / Ghost Review / Clear Reward — 복기와 마무리

■ 종목별 적용
  러닝:  리듬 맞을 때 Timing Pulse, 페이스 유지 구간 Step Combo, 구간별 Match Rate
  복싱:  잽 명중 Hit Glow, 콤보 연결 Step Combo, 회피→반격 성공 시 짧은 연출
  농구:  플랜트 풋 정확 착지 Hit Glow, 전환 타이밍 일치 Timing Pulse

■ 원칙
  - 실패에는 벌점을 주지 않는다. 성공한 순간에만 가볍게 보상한다.
  - 실전에서는 숫자·텍스트 보상을 줄이고 발광·맥동 같은 순간 피드백만 남긴다.
  - 보상이 다음 동작의 시야를 가리면 안 된다 (투사면·시야 제약 안에서).

■ 결론 카피
  NEWTON의 보상은 잘한 것을 칭찬하려는 장치가 아니라,
  잘하고 있다는 감각을 리듬으로 돌려주는 짧은 신호다.

12. 리포트 & 다음 세션 보정 로직 보드
================================================================================

보드 제목: 오늘의 수행이 다음 세션의 난이도를 만든다

핵심 문장:
  세션이 끝나면 NEWTON은 오늘 수행을 요약하고, 어려웠던 구간을 찾아
  다음 세션의 사전 익히기 시간·난이도·웨어러블 개입값을 자동으로 조정한다.
  리포트는 점수 통보가 아니라, 다음 세션을 설계하는 입력값이다.

■ 리포트 → 보정 루프
  오늘 수행 로그 (Pack 일치도 / 숙련 근접도 / 안전·보조 기록 / 피로 후 유지력)
  ↓
  어려웠던 구간 식별 (어느 단계·어느 동작에서 오차·개입이 몰렸는가)
  ↓
  다음 세션 보정값 산출
    · 사전 익히기 시간   — 어려웠던 구간은 분해·반복 늘림
    · 난이도             — 입문 ↔ 기본 ↔ 원본 근접 이동
    · 웨어러블 개입값     — SAFE/BOOST/LOAD/QUIET 강도 조정
  ↓
  다음 세션 추천 (Pack·단계 구성 제안)

■ 리포트 항목 (공통)
  항목            내용
  ──────────────────────────────────────────────
  Pack 일치도      순서·방향·경로·리듬을 Pack답게 유지했는가 (%)
  숙련 근접도      타이밍·리듬 안정성·착지·반응 품질
  안전·보조 기록   SAFE/BOOST/LOAD/QUIET 개입이 언제·왜 작동했는가
  피로 후 유지력   후반 리듬·보폭·반응 저하 정도
  어려웠던 구간    다음 세션에서 보강할 단계·동작

■ 종목별 리포트 초점
  러닝:  페이스 유지 · 후반 리듬 · 보폭 안정성 · BOOST 개입 구간
  복싱:  회피 타이밍 · 잽 타겟 성공률 · 가드 유지 · 중심 흔들림 · QUIET 개입
  농구:  첫 발 타이밍 · 플랜트 풋 안정성 · 백스텝 거리 · 착지 안정성 · LOAD 개입

■ 보정 예시
  러닝  "후반 리듬이 800m 이후 무너졌어요 → 사전 익히기 시간 +1세트"
  복싱  "회피 후 복귀가 늦었어요 → 사전 익히기에서 복귀 스텝 반복 추가"
  농구  "플랜트 발 착지가 흔들렸어요 → 플랜트 타이밍 분해 단계 추가, SAFE 강도 ↑"

■ 결론 카피
  리포트는 세션의 끝이 아니라 다음 세션의 시작이다.
  오늘 어려웠던 구간이 내일의 사전 익히기가 되고,
  오늘의 안정성이 내일의 난이도를 연다.

13. 발 제스처와 세션 전환 로직
================================================================================

전제:
  앱은 세팅까지. 운동 중 조작은 발 두 번 탭.
  바닥/벽면 UI는 단계별로 Step-type에서 Prediction-type으로 바뀐다.

■ 발 두 번 탭 = 단계 전환 제어 (상태별로만 인식)
  상태              발 두 번 탭 의미
  ──────────────────────────────────
  준비 완료          운동 시작
  스트레칭 완료 화면   사전 익히기로 이동
  사전 익히기 완료     실전 운동으로 이동
  일시정지 상태       다시 시작
  운동 종료 확인 화면  세션 종료
  실전 운동 수행 중    잠금(인식 안 함)

■ 안전 규칙
  운동 수행 중       → 발 제스처 잠금
  ↓
  단계 완료/정지 상태 감지
  ↓
  "다음 단계로 갈까요?" 안내 UI 노출
  ↓
  발 두 번 탭
  ↓
  다음 단계 진입

  ※ 움직이는 중 발이 튀면 오작동처럼 보이므로,
    완료·정지 상태에서만 제스처를 활성화한다. (복싱 잽·회피 중 특히 중요)

전체 결론
================================================================================

와이어프레임은 화면 배치보다 먼저,
"어느 단계에서 얼마나 친절하게 보여주고, 언제부터 방해 없이 예측하게
만들 것인가"를 보여주는 구조로 짜야 한다.

  처음에는 밟게 하고(스트레칭),
  중간에는 이해시키고(사전 익히기),
  실전에서는 예측하게 만든다(실전 운동).

  Pack 유형 = 무엇을 배울지
  난이도    = 어떻게 보여줄지
  개입 모드 = 몸에 어떤 물리 감각을 줄지

  러닝 = 밟는 리듬 → 예측하는 페이스 (지면)
  복싱 = 보는 자세 → 반응하는 대련 (벽면)
  농구 = 잡는 중심 → 터지는 전환 (지면)
