# NEWTON 공유 디자인 토큰 — 모바일 ↔ 벽 투사

한 브랜드, 두 매체: 모바일 = 잉크(반사광) / 벽 = 빔(발광).
같은 토큰을 매체별 재질로 번역한다. (피그마 BX-튜터링 = 정본)

- 벽 스케일(1인칭 가독 기준): **최소 26px** — 아이브로 30 / 코너 타이틀 46 /
  센터 타이틀 58 / 대수치 76–128 / 라벨 28–30 / 캡션·CTA 30–34.
  웨이트 500·600·700(과볼드 900 금지). 글로우 = 폰트 크기 비례(px×0.22, 3–14 클램프).

## 형태·레이아웃 (벽 1600×1000 = 500px/m)

- 라운드 척도: 카드 24 / 칩·필 10–27(pill) / CTA 필 31.
- 존 규율: 중앙(x460–1140) = 인물 전용(텍스트 금지) / 좌·우 컬럼 = 정보 /
  좌상 코너 = 아이덴티티(`hudLockupCorner`) / 하단 밴드 = CTA·캡션 1개.
- 레이어: 배경(GridScan·Prism, 5) → HUD(6) → 인물(7) → 정보 카드·CTA·캡션(8, `ctaCtx`).
  정보 카드는 항상 최상층(방송 그래픽 규율).

## 재질 (벽 전용)

- 잉크 위계: 인물 0.985 / 벽 HUD 0.68 / 배경 그리드 0.72·강도 1.15.
- 카드 낙아웃: 밝은 광면 `rgba(255,246,234,0.94)` + 다크 잉크 텍스트 —
  "빛을 안 쏜 영역 = 검정" 지각의 재현. 진짜 알파 구멍은 금지(뒤 레이어 비침).
- 네온 래퍼 주의: 원색 필 칩·다크 텍스트는 반드시 `__rawFill`/`__rawFillText`
  (래퍼가 크림 코어로 탈색시킴).
