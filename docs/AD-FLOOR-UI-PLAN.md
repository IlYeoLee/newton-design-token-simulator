# 대형 광고용 바닥 UI — 구성·발전 계획

> 유저 2026-08-07: *"거의 대형 광고에 넣을 건데 우리 고작 그 작은 거 몇 개면 그렇잖아."*
> 플레이트: `화면 기록 2026-08-07 5.26.39.mov` (6.6s · 1794×1016 · 60fps · 실사 코트 · 인물+공, 바닥 UI 없음)

## 0. 진단 — 왜 약해 보이나

| 원인 | 근거 |
|---|---|
| **프레임 점유율이 낮다** | 바닥이 프레임 하단 ~40%, 그 안의 발자국 2~5개. 인물·공에 시각적으로 밀린다 |
| **설계 목표가 정반대다** | 제품 UI 의 기준은 **투사 물리 + 가독 하한**(docs/FLOOR-LEGIBILITY.md) — "최소한만 그린다". 광고의 기준은 **프레임 임팩트**다 |
| **정지 프레임 기준으로 깎았다** | 파동(rip)을 0 으로 끈 것은 **알파 추출**(정지 윤곽) 때문이었다. 영상에서는 시간축 자산이다 |

**결론: 제품 룩을 광고 때문에 바꾸지 않는다.** 광고용 프리셋을 따로 둔다 —
`src/mark-look.json` 은 제품 정본이고, 광고는 그 위에 얹는 오버레이(`_presets.json` 과 같은 규약).

## 1. 구성안 — 6.6초 컷에 맞춘 순서

시스템의 **의미 순서**를 그대로 쓴다(새 문법 0개): 경로 → 자리 → 시범 → 판정.

```
0.0 ~ 1.0   빈 코트 + 자막 "watch my signature move"      바닥 UI 없음(대비를 만든다)
1.0 ~ 2.0   경로선 draw-on ×3 순차 (0.3s 간격)            흐름이 **먼저** 온다
2.0 ~ 3.5   발자국 5개 순차 등장 Preview → Active         밟을 자리
3.5 ~ 5.0   고스트가 그 경로를 밟고 지나간다               어떻게 하는지 (코치 궤적)
5.0 ~ 6.6   인물 첫 착지 → Hold → Success                 지금 네 차례
```

왜 이 순서인가: 제품에서도 실전 직전(`BK_C2` 관찰 7.2초)이 **경로선이 전부 깔린 유일한 화면**이다
(`_sbTrail`, LINK.trail). 광고는 그 7.2초를 **시간축으로 펼친 것**이지 다른 화면이 아니다.

## 2. 발전 3층 — 전부 기존 어휘로

### A층 · 스케일 (프레임 점유율)
- `FOOT_LEN_M` 0.30 → **광고 프리셋 0.42** (발 잉크 면적 ×2). 제품은 그대로.
- 경로선 두께·글로우 ↑ — `_gain` 0.42(2급) → **0.7**. 광고에선 경로가 주인공에 가깝다.
- 콘텐츠 밴드(942~1980, **1204px**)를 꽉 채운다. 지금은 절반도 안 쓴다.

### B층 · 흐름 (시간축 — 여기가 핵심)
- **경로선 순차 draw-on**: `_prog` 가 이미 있다. 세 구간에 0.3s 시차만 준다.
- **도트 흐름**(촤르르륵): 이미 구현됨(`dotList` 흐름 + 스퀴즈). 광고에선 속도 ×1.4.
- **파동(rip) 부활** — 광고 프리셋에서만. 정지 추출용으로 0 으로 끈 것이라 영상에는 손실이 없다.
- **완료 팡**: `743868a` 의 완료 팡 어휘를 마지막 판정에 붙인다.

### C층 · 고스트 (코치 궤적)
- `BK_FIN` 의 규약 *"Ghost Review — 커리 궤적과 내 스텝 겹쳐 보기"* 를 **실전 직전으로 끌어온다.**
- 자산이 이미 있다: `gh`(ghost FootMark) · `drawCurveArrow`(궤적) · `ghost/` 클립.
- 연출: 고스트 발자국이 경로를 0.5s 간격으로 밟고 지나간 뒤 사라진다 → 인물이 그 자리를 밟는다.

## 3. 하지 말 것

- **새 그래픽 어휘 추가 금지.** 광고에서 새로 만든 것은 제품에 없어서, 광고를 본 사람이 제품에서 그것을 찾는다.
- **제품 정본(mark-look.json·TOK) 직접 수정 금지.** 광고 값은 오버레이로만.
- **자막과 바닥 UI 를 같은 띠에 두지 말 것.** 플레이트의 자막이 하단 중앙이고 바닥 UI 도 하단이다 —
  광고에선 자막을 올리거나 바닥 UI 를 프레임 중앙으로 올린다(코너핀 조정).

## 4. 다음 액션

1. 광고 프리셋(`ad`) 을 look 오버레이로 신설 — A층·B층 값만 담는다
2. 순차 draw-on 시차 파라미터 (`trailStagger`)
3. 고스트 경로 밟기 연출 — 실전 직전 구간에 붙인다
4. 그 상태로 `BK_C2` 관찰 구간을 2K·알파로 추출해 플레이트에 코너핀 합성
