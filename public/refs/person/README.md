# 인물 질감 레퍼런스 (유저 확정 2026-08-01)

이 다섯 장이 인물 룩의 목표다. 랩(`personlab-live.html`) 하단에 항상 띄워 둔다 —
값을 만지다 보면 기준을 잃는데, 기준이 화면에 없으면 매번 다른 방향으로 흘러간다.

## 공통 성질 (이게 '이 느낌'의 실체다)

1. **검은 배경.** 인물 외곽이 배경으로 완전히 녹는다. 아웃라인이 없다.
2. **밝기 = 깊이/근접.** 카메라·광원에 가까운 면이 희고, 멀어지는 면이 검정으로 떨어진다.
   사진의 질감(모공·옷 무늬)이 아니라 **형태**가 밝기를 정한다.
3. **가장자리가 어둡다.** 실루엣 경계로 갈수록 검정. 반대로 안쪽 두꺼운 곳이 밝다.
   → 우리 두께장(실루엣 안쪽 깊이)이 그대로 이 역할을 할 수 있다.
4. **하이라이트는 순백까지 뚫는다.** 손끝·팔뚝·어깨 같은 가장 가까운 지점만.
5. **계조가 매우 매끄럽다.** ref-31 만 예외로 의도적 등고선(포스터화) 변주.

## 뉴턴 색으로 옮기는 규약

무채(검정→흰색) 축을 그대로 쓰지 않는다. 규칙 ①(유채 4색)을 지키면서
**뉴턴 LUT 를 명도축으로 쓴다**:

    가장자리(깊이 0) → RED 어두운 쪽      = 배경으로 떨어지는 자리
    중간             → CORAL → SAND
    가장 깊은 곳     → PRISM(거의 흰빛)   = 순백 하이라이트의 등가물

즉 지금 매핑의 **반대**다. 현재는 가장자리가 밝고(SAND) 안쪽이 진한데(RED),
레퍼런스는 가장자리가 어둡고 안쪽이 밝다.
