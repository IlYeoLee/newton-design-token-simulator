# NEWTON · Design Token Simulator

외부 전문가 움직임 데이터 → 디자인 토큰 공식 → 빔프로젝터 UI 투사 → 따라하기 검증 시뮬레이터.

- **러닝**: Fukuchi et al. 2017 (CC BY 4.0) — 무릎 장착 프로젝터, 지면 발자국/타이밍 링
- **복싱**: Zenodo 14965635 IMU (CC-BY-4.0) — 전방 UST 스테이션, 벽면 타겟+전문가 고스트 실루엣
- **농구**: NBA SportVU 2015-16 — 연구/프로토타입 용도 한정(상업적 재배포 금지), 지면 플랜트 마크+컷 방향

핵심 검증: 투사면 물리 제약(GPU 클리핑), 시야∩투사면 교집합 배치, 무릎 투사 안정화(스프링-댐퍼),
1인칭 VOR 시선, 판정 루프(Pack 일치도) — 계측 기반 캘리브레이션 완료.

```bash
npm install
npm run dev    # http://127.0.0.1:5199
npm run build  # dist/
```

비상업 연구·프로토타입 목적. 각 데이터 원 라이선스를 따릅니다.
